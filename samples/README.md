# Samples

Each directory is an independently runnable Ktor application. Run one at a time; all samples listen on `http://localhost:8080`.

| Binder | Module | Run |
| --- | --- | --- |
| kotlinx.serialization JSON | [`kotlinx-json`](kotlinx-json) | `./kotlin run --module samples/kotlinx-json` |
| Gson | [`gson`](gson) | `./kotlin run --module samples/gson` |
| Jackson | [`jackson`](jackson) | `./kotlin run --module samples/jackson` |
| Basic (default reflection binder) | [`basic`](basic) | `./kotlin run --module samples/basic` |
